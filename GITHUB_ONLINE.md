## 🔄 Atualizar Online

Cada vez que você faz:
```bash

```

**Automaticamente:**
1. ✅ Código aparece no GitHub
2. ✅ GitHub Actions começa a testar
3. ✅ Resultado aparece em Actions
4. ✅ Se sucesso, executável é compilado
5. ✅ Se criar tag, release é publicada
